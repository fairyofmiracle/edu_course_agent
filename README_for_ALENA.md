
## Что сделала

Исправлена обработка итоговой аттестации и изменения продолжительности курса.

- Статус аттестации больше не меняется автоматически с `unset` на `none` после двух сообщений без явного ответа методиста.
- При обработке истории диалога учитывается явная отмена аттестации.
- Явно указанные часы аттестации сохраняются, даже если её форма ещё не определена.
- Добавлено распознавание запросов на изменение общей продолжительности курса.
- Проверено, что часы аттестации входят в общую продолжительность, а часы учебных модулей пересчитываются отдельно.

**Проверочный сценарий:** курс 24 часа, аттестация 3 часа, модули 21 час. После изменения продолжительности на 36 часов аттестация остаётся 3 часа, модули пересчитываются до 33 часов.

## Изменённые файлы

- `backend/app/brief_guard.py` — правила обработки аттестации.
- `backend/app/planner.py` — распознавание запросов на изменение продолжительности.
- `backend/app/agent.py` — выбор инструмента `update_brief`.
- `backend/tests/test_own_cases.py` — регрессионные и интеграционные тесты.
