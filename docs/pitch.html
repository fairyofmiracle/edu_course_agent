Студия методиста

Модель пишет. Код не выпускает.

Рабочее место методиста: программа слева, диалог справа, в конце проверка и файл, который можно отдать в нормоконтроль.

Не ещё один чат

Три места, где методист теряет время.

Часы

Переписал модуль — сумма поплыла. Ищешь расхождение в плане и в итоговой строке.

Токены

Чат пишет весь курс сразу, хотя структура ещё не согласована.

Норма

В тексте появляются приказ и код профстандарта, которых не было в материалах.

Часы

«Месяц» не становится 72 часами.

  • Объём задаёт только методист.
  • После каждого шага модели Python пересчитывает программу.
  • На экране и в файле одна цифра: сколько часов из скольких.

Токены

Комплект не пишется, пока каркас не утверждён.

  • Пока бриф неполный, вопросы задаёт код. Модель не вызывается.
  • В шлюз уходит снимок одного шага, не весь курс и не весь файл.
  • Один ход — один инструмент.

Норма

Код не подписывает то, чего не было.

  • Приказ и код трудовой функции берутся из файла или проверяемой ссылки.
  • Два шаблона: общеразвивающая, приказ № 629; повышение квалификации, 273-ФЗ и приказ № 266.
  • Вкладка «Проверка» считает расхождения без модели, до выгрузки.

Демонстрация

Сырой запрос, как от заказчика.

  • Курс по кибербезопасности, «примерно на месяц», без числа часов.
  • На экране нет 72. Есть один вопрос и кнопки ответа.
  • Обещание «пойдут работать» в программу не записываем.

Каркас

72 часа сходятся без второго вызова шлюза.

  • Методист задал 72. Модель разложила модули.
  • Код собирает сумму: практика, аттестация, шаг в полчаса.
  • Лекции и тесты ещё закрыты. Комплекта нет, токены на него не ушли.

Ворота

Утвердить каркас.

До кнопки правим структуру. После неё собираем тест с ключом, практику и слайды урока. Снять утверждение можно и вернуться к каркасу.

Результат

Сначала проверка. Потом файл.

  • Часы, два оценочных средства на каждый результат, источники.
  • DOCX собирает сервер из тех же цифр, что на экране.
  • Рядом презентация и JSON. Методист не копирует текст из чата в Word.

Как устроено

Один клиент к шлюзу. Ключ не в браузере.

  • Экран на Next.js. Правила, аудит и выгрузка на FastAPI.
  • Только Cloud.ru и GigaSchool. Чужой адрес обрывается до запроса.
  • Версии курса. Если две вкладки сохраняют разом, вторая получает отказ, а не тихую порчу.
