## 0:00–0:45 · Приветствие, кто мы, чем отличаемся

**Показываю:** сразу **вкладка с живой студией на сервере** (не localhost «с коленки» — уже развёрнуто).

**Говорю:**

Здравствуйте. Спасибо, что уделили нам время на защиту.

Мы — команда **Not_Idea**. На хакатоне сделали «Студию образовательных программ» для методиста АЦР. Продукт **уже развёрнут на сервере** — сейчас пройдём по живому стенду.

Мы построили архитектуру на **Next.js** и **Python / FastAPI**: рабочее место снаружи, правила, аудит и выгрузки — на сервере. Модель пишет тексты. Код следит за часами и правилами и не отдаёт результат без проверки.

**Чем мы отличаемся** от типичного «промпт → красивый текст»:

**Время** — путь методиста: скелет → материалы курса → проверка → файл. Меньше ручной сборки и поиска, где разъехались часы.

**Экономичность** — вопросы по неполному запросу пишет код; в шлюз — один шаг, не весь курс; материалы — только после утверждения структуры.

**Надёжность** — часы и источники проверяет код; перед выгрузкой — отдельная проверка без модели.

Сначала коротко — структура в GitHub и API, затем живой сценарий в вебе.
