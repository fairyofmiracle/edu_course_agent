# Описание проекта к техничке

Студия образовательных программ облегчает работу методиста АЦР: быстрее собрать программу по запросу заказчика так, чтобы часы сошлись, разделы были на месте и результат можно было проверить и отдать дальше — без долгой ручной сборки всего с нуля.

Модель помогает создавать содержание: формулировки компетенций, названия и описания модулей, тексты лекций, вопросы теста, практические задания и слайды — то, что обычно долго писать руками.

Код берёт на себя другое: берёт из запроса только то, что методист явно назвал, спрашивает, если бриф неполный, после каждого шага модели пересчитывает академические часы, не открывает подготовку учебных материалов, пока методист не утвердил скелет программы, проверяет источники и не даёт выгрузить результат, пока часы и обязательные разделы не сошлись. Так методист получает и живой текст, и программу, которую можно проверить и отдать дальше.

## Что сделали

Собрали полный контур методиста. Неполный запрос не превращается в программу: студия задаёт уточняющие вопросы (их пишет код, без вызова модели) — тип программы, точный объём, аудитория и уровень, форма обучения, аттестация. Объём появляется только когда методист назвал число академических часов; приблизительные формулировки и часы из старого файла-образца сами в программу не переезжают. Приказ и код трудовой функции не выдумываются.

Когда бриф собран, модель собирает скелет программы: компетенции как знания, умения и навыки, учебный план и распределение часов с шагом 0,5. Сумма модулей и аттестации равна объёму. На этом шаге ещё нет лекций, семинаров и тестов — только структура. Методист смотрит скелет и нажимает «Утвердить каркас»: после этого студия готовит рабочие материалы курса — тест с ключами, практические задания, тексты лекций и слайды. С ключом шлюза их пишет модель; если ключа нет или шлюз недоступен — код накидывает материалы по скелету и прямо пишет в чат, что это не модель, чтобы никто не перепутал.

Вкладка «Проверка» и серверный аудит без модели смотрят сходимость часов, обязательные разделы, два оценочных средства на каждый результат обучения и источники. Нормативная основа: для общеразвивающей программы — приказ Минпросвещения № 629; для повышения квалификации — 273-ФЗ и приказ Минобрнауки № 266; приказ № 499 помечается как утративший силу. Ссылки проверяются по коду ответа, текст приказа не скачивается.

Поддержаны оба шаблона АЦР — общеразвивающая (сертификат) и повышение квалификации (удостоверение). Объём от 16 академических часов; длинные программы собираются модулями-блоками (в том числе прогоны на 16, 36, 72 и стажировку 256 часов). «Мои курсы» хранит версии; «Копия» заводит курс под другую аудиторию. Конфликт параллельного сохранения отклоняется кодом 409. «Офлайн-пример» показывает готовую программу на 24 часа без модели.

Открытые кейсы прогнаны, автотесты покрывают бриф, часы, аудит, выгрузки и политику адресов шлюза. Есть инструкция воспроизводимого запуска и сценарий защиты.

## Какой стек используем

Рабочее место методиста сделано на Next.js, React и TypeScript. Вся логика курса — на Python и FastAPI: диалог, скелет программы, учебные материалы, аудит, нормативные проверки, прогон запроса и сборка файлов. Интерфейс к модели сам не обращается: запросы к шлюзу идут только с сервера.

Данные курсов и версий храним через SQLAlchemy. На сервере — PostgreSQL (в разработке — SQLite). Поднимаем стек Docker Compose: база, API и веб на порту 8000; для отладки можно запустить локально без контейнеров.

К нейросети подключены два разрешённых шлюза: Cloud.ru Evolution с моделью писателя GigaChat-3-Pro и шлюз хакатона GigaSchool. Любой другой адрес, в том числе OpenAI, код отклоняет ещё до запроса. Если при сборке скелета шлюз отвечает 429 или 5xx, запрос повторяется.

Основные выгрузки — программа в DOCX, презентация в PPTX и данные в JSON — собирает сервер. Форматы для LMS (Moodle XML, GIFT, CSV) собирает браузер.

## Что отдали

Рабочая студия с полным сценарием методиста: новый курс, уточнения, скелет программы, утверждение структуры, рабочие материалы курса, проверка, выгрузки, версии и копия курса. Демонстрационная программа на 24 часа без модели. Пять открытых запросов с эталонными чек-листами. Документация запуска и защиты. С ключом — генерация по теме запроса; без ключа — честный запасной контур на коде.
