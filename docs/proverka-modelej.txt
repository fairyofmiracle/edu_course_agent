Проверка трёх моделей на шлюзе GigaSchool
=========================================

Официальный список кабинета
---------------------------
Это и есть все разрешённые имена. Других нет.

  Модель                                         Вход, ₽   Выход, ₽   Роль в кабинете
  GigaChat/GigaChat-3-Pro                          73,03     176,39   быстрая, без рассуждений, для агентов
  ai-sage/GigaChat3.5-432B-A28B-Reasoning          96,22     288,60   сложный анализ, код, много шагов
  ai-sage/Giga-Embeddings-instruct-3B              32,22       0,00   векторы, не генерация

Цены как в кабинете: рубли за 1 млн токенов.


Что из этого реально собирает курс
----------------------------------
  Pro          живой chat. На «ок» шлюз накручивает ~1200 prompt.
               На «Figma для музея» ушло 1654 + 11 токенов ≈ 0,12 ₽,
               но ответ был почти пустой (11 токенов). Каркас тогда
               подставил код.

  Reasoning    дороже Pro на ~32% вход и ~64% выход. Отвечает 200,
               content пустой, всё в reasoning, finish=length.
               Function calling в карточке есть, на этом шлюзе
               OpenAI tools дают 400. Как писатель каркаса не ставим.

  Embeddings   не чат. /chat/completions → 404. Поиск по каталогу
               потом, не сборка программы.

  10B и прочие имена из старых примеров → 400 llm_model_not_allowed.


Как распределить фазы
---------------------
Три имени — не три фазы оркестрации.

  бриф, часы, тип     код: модель не додумывает объём
  знакомые кейсы      код: не жжём лимит на то, что уже собрано
  чужая тема / план   Pro: это официальная модель «для агентов»
  вопросы методисту   код: дешёвой chat-модели нет
  комплект документов код
  Reasoning           не вызываем: дороже и молчит в content
  Embeddings          не вызываем из агента

Обе текстовые роли в .env сейчас Pro. Это не запасной план,
а то, что кабинет сам рекомендует для агентов.


Живой вызов Pro
---------------
Тема не из кейсов: «Основы Figma для музея», 20 ч.

  1654 prompt + 11 completion, 1 вызов;
  модель почти ничего не вернула;
  студия подставила общий каркас из трёх модулей.

Главный риск — не «модель не вызвали», а дорогое молчание Pro.
Каталог страхует документ, не заменяет шлюз.


Почему не ставим Reasoning на каркас
------------------------------------
Кабинет пишет: сложные задачи, function calling, structured output.
На шлюзе хакатона:

  * tools в стиле OpenAI — 400;
  * ответ уходит в reasoning, не в content;
  * рубль дороже, чем у Pro.

Пока content пустой, платить за неё больше смысла нет.


Что поменяла после сверки с кабинетом
-------------------------------------
  * дефолты больше не указывают на запрещённую 10B;
  * клиент сам уводит 10B и Embeddings на Pro;
  * учебный план идёт в Pro, каталог — если JSON пустой.
