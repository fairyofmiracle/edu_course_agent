Что показала живая сборка
-------------------------
S1 и S2. Pro написала понятные модули: Excel → сводная таблица,
офисный Python → отчёт, не школьная игра. Профиль generic.

S3. «Два месяца» не стали часами. После ответов каталог склеил
модули из длинного заголовка-предложения. Заголовок чищу: «курс по …»,
без «примерно на два месяца».

S4. 40 часов, не 160. B/02.7 в компетенции не попал. План каталога
пока шаблонный: «Основные понятия / Практика / Раздел 4».

S5. Учитель без нейросетей не свалился в кейс 2: нет A/01.6 и ChatGPT.
Pro сама написала цифровую гигиену и российские платформы.


Что починила по ходу
--------------------
  * «без опыта» + Python больше не считает программу школьной.
  * «зачёт» читается как аттестация.
  * «для бухгалтерии» внутри названия не становится аудиторией.
  * аттестация «игра или чат-бот» только у школьного Python.
