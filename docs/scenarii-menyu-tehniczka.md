# Сценарий А — Кейс 4, кибербезопасность (неполный запрос)

**Критерии:** соответствие кейсу ★★★★★, качество (валидация) ★★★★, понятность ★★★★.

### Момент 1 — Старт

**Делаю:** «Новый курс».

**Говорю:** Показываю пустую программу и серые блоки — комплект **заперт**, пока нет утверждённого каркаса.

### Момент 2 — Сырой запрос

**Делаю:** вставляю и отправляю.

```
Сделайте курс по кибербезопасности для студентов колледжа, примерно на месяц, чтобы после него ребята могли пойти работать в эту сферу.
```

**Говорю:** Это **намеренно неполный** запрос из кейса. Жду **вопросы**, не каркас. Показываю: **нет 72**, «месяц» не превратился в часы.

**На что ткнуть:** кнопки типа / аттестации / формы; счётчик вопросов ≤ 5; план **не** пошёл.

### Момент 3 — Ответы методиста (одним сообщением)

**Делаю:** вставляю и отправляю.

```
Повышение квалификации с удостоверением.
72 академических часа.
Студенты 3 курса специальности «Информационные системы и программирование», знают основы сетей и Linux.
Форма обучения: очно, занятия на базе колледжа.
Итоговая аттестация: экзамен с практическим заданием на стенде.
```

**Говорю:** Шаблон **ПК**, объём **ровно 72**. Модель пишет каркас; код сверит сумму и шаг 0,5.

### Момент 4 — Каркас + перерасчёт часов + токены

**Делаю:** сумма часов («X из 72»), вкладка компетенций, строка токенов в чате. При втором мониторе — кадр `под капотом`: «модель 68+6» → «код 70+2».

**Говорю:** ЗУН, начальный уровень. **Часы:** методист задал 72 → модель написала модули → **код** `rebalance` свёл сумму **без второго LLM**. Токены в чате — цена хода; вопросы и пересчёт — **0**. Без обещания «сразу на работу» в результатах.

### Момент 5 — Комплект и финиш

**Делаю:** «Утвердить каркас» → «Собрать комплект» (или **вкладка 2**, если долго).

**Делаю:** «Проверка» → «Выгрузить → Программа».

**Говорю:** Два средства на результат, экзамен на стенде в структуре, DOCX с сервера — **готовый артефакт**.

# Сценарий Б — Кейс 1, Python 16 ч, школьники

**Критерии:** качество ★★★★★, соответствие ★★★★, понятность ★★★★.

### Момент 1

**Делаю:** «Новый курс».

### Момент 2 — Полный запрос сразу

**Делаю:** вставляю целиком.

```
Нужна дополнительная общеразвивающая программа «Первые шаги в Python» для школьников 8 и 9 классов без опыта программирования. Объем 16 часов, занятия очно по 2 часа два раза в неделю. Практики должно быть не меньше половины всех часов. В конце каждый ученик защищает небольшой проект, например простую игру или чат-бота. Нужны итоговый тест на 10 вопросов и слайды для первых двух занятий.
```

**Говорю:** **Общеразвивающая**, сертификат, **16 часов** — не ПК. Вопросов мало или нет — бриф полный.

### Момент 3 — Каркас

**Делаю:** сумма **16**, практика ≥ 8 ч, нет профстандарта в программе.

**Говорю:** Календарь 8×2 ч — смотрим в плане; сложность для нулевого уровня.

### Момент 4 — Комплект

**Делаю:** «Утвердить каркас» → «Собрать комплект».

**На что ткнуть:** **10 вопросов** в тесте; слайды к **занятиям 1 и 2**; защита проекта в аттестации.

### Момент 5

**Делаю:** «Проверка» + выгрузка DOCX.

**Говорю:** Это эталон **минимального объёма** и шаблона **ОР** из открытого кейса.

# Сценарий В — Кейс 2, ИИ для учителя, 36 ч

**Критерии:** соответствие ★★★★★, качество (источники) ★★★★.

**Подготовка:** приложить шаблон ПК + файл/упоминание профстандарта «Педагог», если проверяющий даст файлы на площадке.

### Момент 2 — Запрос

```
Программа повышения квалификации «Искусственный интеллект в работе учителя» для учителей школ Ингушетии, 36 часов, очно-заочно с применением дистанционных технологий. Учителя должны научиться готовить с помощью нейросетей планы уроков, задания и проверочные работы, а также понимать риски и правила безопасного использования ИИ в работе с детьми. Итоговая аттестация в форме зачёта по портфолио из трёх материалов, созданных с помощью ИИ. Использовать только сервисы, которые доступны в России.
```

**Говорю:** Портфолио из **трёх** материалов; сервисы — российский контур (GigaChat, YandexGPT и т.д., не «запрещённый» список).

# Сценарий Г — Кейс 3, анализ данных 72 ч + образец

**Критерии:** качество ★★★★★, соответствие ★★★★★.

**Подготовка:** прикрепить файл образца (например программа на 248 ч), в тексте запроса указать **72 ч**.

### Момент 2 — Запрос

```
Нужна программа повышения квалификации на 72 часа «Анализ данных на Python» для сотрудников региональных отделений банков, которые сейчас работают в Excel. Формат очно-заочный, срок 4 недели. Основные темы это pandas, визуализация, SQL для выгрузки данных и основы статистики. Итоговая аттестация в виде защиты проекта на обезличенных банковских данных. Прикладываю нашу прошлую программу, структуру можно взять оттуда, но содержание нужно новое. Слайды нужны для модуля про pandas.
```

**Делаю:** прикрепить файл образца.

### Момент 3 — Главный «вау» для жюри

**Говорю:** В программе **72 часа**, не 248 из файла. Тема — **анализ данных**, не копия текста образца. Структура разделов может напоминать образец, **дословные 12 слов** — ошибка в проверке.

**На что ткнуть:** модули pandas / viz / SQL / статистика; вводный Python для ex-Excel; слайды модуля **pandas**.

### Момент 4

Утвердить → комплект → проверка → DOCX.

# Сценарий Д — Кейс 5, DevOps стажировка 256 ч

**Критерии:** соответствие ★★★★★, качество часов ★★★★★.

**Подготовка:** приложить образец стажировки BA с **кривой итоговой строкой**.

### Момент 2 — Запрос

```
Нужна программа повышения квалификации в форме стажировки «DevOps-инженер от Linux до CI/CD» на 256 часов. Слушатели проходят стажировку в ИТ-компаниях региона, вся работа самостоятельная под руководством наставника от компании, аудиторных занятий нет. Итоговая аттестация занимает 2 часа и проходит в форме защиты отчёта о стажировке. Срок около двух месяцев, не больше 4 часов в день. Возьмите за образец структуры нашу стажировку по бизнес-анализу.
```

### Момент 3 — Каркас (главное на техничке)

**Говорю:** **254 ч СРС + 2 ч аттестации** = 256. Лекции, практики, лабораторные — **ноль**. Ошибка часов из чужого образца **не переехала**.

**На что ткнуть:** строки плана; итоговая аттестация **2 ч** внутри объёма; нагрузка ≤ 4 ч/день в графике.

### Момент 4

Если времени мало — **не ждём** полный комплект на 256 ч: показываем каркас + вкладку 2 с заранее собранной стажировкой или фрагмент «Проверки».
