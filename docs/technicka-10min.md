# Скрипт защиты

Этот файл берём с собой. Читаем вслух то, что под словом «Говорю». «Делаю» не произносим.

Перед входом студия уже открыта на порту 8000, ключ в `.env`, контейнеры `db`, `api`, `web` живые. В соседней вкладке лежит курс, собранный до защиты: его открываем, только если комплект не успеет.

Одна фраза на все десять минут: модель пишет, код не выпускает.

## 0:00. Спасибо и кто мы

Говорю:

Спасибо, что слушаете. Сегодня много чатов, которые просто пишут программу. У нас модель пишет текст, а код не выпускает её, пока не сошлись часы, шаблон и источники. Сейчас это будет видно: в запросе нет часов, и число само не появится.

## 0:30. Пустой курс

Делаю: «Новый курс».

Говорю:

Справа чат, слева пустая программа. Лекции, семинары и тесты серые. Их откроет только кнопка «Утвердить каркас». До этой кнопки комплекта нет.

## 0:50. Запрос без часов

Делаю: вставляю в чат и отправляю.

```
Сделайте курс по кибербезопасности для студентов колледжа, примерно на месяц, чтобы после него ребята могли пойти работать в эту сферу.
```

Жду вопросы. Пальцем показываю, что числа 72 нет, и что на тип, аттестацию и форму есть кнопки.

Говорю:

Вот здесь другие допишут 72 сами. «Месяц» у нас остался сроком. Вопросы написал код, не модель. План не начался, токены на сочинение дыр не тратятся. Работу после курса мы тоже не обещаем.

## 2:10. Один готовый ответ

Делаю: вставляю целиком и отправляю. Кнопки не собираю по одной, чтобы не ждать второй круг.

```
Общеразвивающая программа с сертификатом.
72 академических часа.
Студенты колледжа, без опыта администрирования.
Итоговая аттестация: экзамен.
Форма обучения: очно.
```

Пока ждём, говорю:

Сейчас модель забирает только эти поля. Компетенции и модули пойдут следующим ходом, когда бриф собран. Линия вверху — таймер в браузере, отдельного запроса к модели за неё нет.

## 2:40. Каркас

Делаю: показываю сумму часов, вкладку компетенций, строку токенов в чате.

Говорю:

Сумма сошлась с объёмом, шаг полчаса. Здесь знания, умения и навыки, не общий абзац. Строка токенов пришла из ответа шлюза: сколько на вход, сколько на выход, сколько всего. Модель получила снимок шага, не весь курс. История короткая, образец режется. Один ход — один инструмент. Часы, тип программы и код трудовой функции после модели проверяет код.

## 4:10. Утвердить

Делаю: «Утвердить каркас». Если до шестой минуты есть запас, «Собрать комплект». Если нет, открываю курс из соседней вкладки и показываю один тест, одно задание и слайд.

Говорю:

До кнопки тестов не было. Комплект пишет модель: шаг до семидесяти секунд, без повтора, общий запас около трёх минут. Повтор есть только на каркасе, если шлюз ответил 429 или 5xx, и не больше трёх раз. Если ключа нет или шлюз молчит, дырку дописывает код, и чат говорит об этом прямо. Лимит на задачу — 25 000 токенов, дальше запрос к модели не уходит.

## 5:20. Проверка и файл

Делаю: вкладка «Проверка», затем «Выгрузить → Программа».

Говорю:

Сначала проверка, потом файл. Часы, два средства на каждый результат, чужой приказ не проходит. Файл собирает сервер в этом запросе, очереди нет. На этом живой проход заканчиваю и готова к вопросам.

## Вопросы

Коротко. Потом показываю экран. За двадцать секунд до конца новую тему не начинаю.

Если спросят, где модель, а где код. Next.js рисует и проксирует. Ходы, инструменты и проверка живут в FastAPI. К шлюзу ходит один клиент.

Если спросят, какие шлюзы. Два адреса: GigaSchool и Cloud.ru. Чужой адрес, включая OpenAI, обрывается до запроса. Если заданы оба ключа, уходит только ключ Cloud.ru.

Если спросят, почему не выдумывает приказ. Номер и код трудовой функции берутся из файла или из проверяемой ссылки. Общеразвивающая программа получает приказ номер 629. Повышение квалификации получает 273-ФЗ и приказ номер 266. Приказ номер 499 помечен как утративший силу. Текст приказа не скачивается.

Если спросят про часы. Академические, шаг полчаса. «Месяц» не становится числом. Аттестация входит в объём. Сумму сверяет код.

Если спросят, где данные. Локально SQLite, в Docker PostgreSQL. Новая версия пишется отдельно. Устаревшее сохранение получает 409. Если API недоступен, список курсов остаётся в браузере.

Если дадут свой кейс. «Новый курс» и их текст. Часы из приложенного образца не переносятся. Тема берётся из запроса. Неполный запрос останавливается на вопросах, так и задумано.

Если спросят, чего нет. Голосовой ввод, поиск по векторам и объектное хранилище. Это следующий шаг, в этой сборке их нет.

Если спросят про токены. Вопросы сочиняет код. В запрос не кладётся весь документ. На бриф уходит бриф, на модуль — один модуль. Потолок ответа режется по шагу, чтобы длинный JSON не обрывался. Температура ноль. Упавший шаг комплекта не повторяем. Строка в чате — расход из ответа шлюза.

## Конец

Говорю:

Спасибо за проверку.

После этого молчу.
