Свои кейсы студии
=================
Это не открытые кейсы хакатона и не скрытые. Ими проверяем живой контур:
тему могут принести любую, профиль не должен срабатывать по случайному слову.

S1. Excel для бухгалтерии
-------------------------
Нужна дополнительная общеразвивающая программа «Excel для бухгалтерии»
для сотрудников бухгалтерии. Объём 24 часа, очно. В конце защита проекта:
сводная таблица по учебным проводкам.

Проверяет: generic, сертификат, нет профстандарта, семинар не про чат-бот.


S2. Python для офиса, без опыта
-------------------------------
Нужна общеразвивающая программа «Python для офиса» для сотрудников
бухгалтерии без опыта программирования. Объём 24 часа, очно. В конце
защита проекта: мини-отчёт из таблицы.

Проверяет: «без опыта» + Python не делает школьную программу.
Нет графика «8 занятий», нет чат-бота, нет языка для восьмиклассника.


S3. Неполный запрос про нейросети
---------------------------------
Сделайте курс по нейросетям для методистов колледжа примерно на два месяца.

Ответы, если спросит:
  тип — общеразвивающая
  объём — 20 часов
  форма — очно
  аттестация — защита проекта: разбор готового промпта

Проверяет: «два месяца» не объём. Сначала вопросы. Не профиль учителя:
методист колледжа — не «учитель + ИИ».


S4. Месяц и 40 часов в одном тексте
-----------------------------------
Нужна программа повышения квалификации «Охрана труда в серверной» на месяц,
40 часов, очно. Слушатели: системные администраторы. Итоговая аттестация —
зачёт. Поставьте код трудовой функции B/02.7.

Проверяет: объём 40, не 160 из «месяца». Код B/02.7 не выдумываем
и в компетенции не ставим. Это не стажировка DevOps.


S5. Учителя без нейросетей
--------------------------
Программа повышения квалификации «Цифровая грамотность учителя» для учителей
школ, 36 часов, очно-заочно. Нейросети и генеративные модели в программу
не входят. Итоговая аттестация — зачёт.

Проверяет: учитель без ИИ — не teacher_ai. Нет A/01.6, нет GigaChat и ChatGPT.
